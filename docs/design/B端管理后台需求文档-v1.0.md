## 3. 功能需求

### FR-B01 主页跳转 Logo（已明确）

- 顶部左侧圆形 Logo，点击跳转主页（B 端主页或 C 端首页，具体指向待确认，见 TBD-B01）。
- Logo 图片待用户提供，默认可先用占位圆形。

### FR-B02 管理员头像（已明确可设置，细节待确认）

- 右上角头像区展示管理员头像。
- 管理员可设置头像（上传/更换方式、尺寸限制、失败提示待确认，TBD-B02）。
- 头像数据来源为后端用户接口（管理员账号），字段待协同。

### FR-B03 用户管理（已明确入口，列表细节待确认）

- 左侧导航提供用户管理入口，点击进入用户管理页。
- 右侧内容区展示用户列表，顶部有查询栏框用于检索。
- 列表字段、查询条件、分页参数建议复用现有 `GET /api/users` 分页接口。
- 新建/禁用/删除用户、重置密码等操作本次设计图未定义，不得自行添加（TBD-B03）。

### FR-B04 文件管理（已明确约束，列表细节待确认）

- 左侧导航提供文件管理入口。
- 核心约束：B 端无法观看用户文件正文，只能管理元数据（标题、所属用户、大小、状态、更新时间等）。
- 当前可复用 `GET /api/files` 公开文件分页；按用户筛选的 B 端文件接口尚未定义，旧的 `/api/files/user/{userId}` 已移除，不能复用于 B 端。
- 是否允许下架/删除文件、状态流转规则本次未定义，不得自行添加（TBD-B04）。

### FR-B05 预留导航（待确认）

- 左侧导航共 5 个按钮位，设计图仅明确其中 2 个（用户管理、文件管理），剩余 3 个名称与功能待确认（TBD-B05）。

### FR-B06 查询栏框（已明确存在，规则待确认）

- 右侧内容区顶部有查询栏框。
- 查询字段、触发方式（回车/按钮/实时）、空结果态待确认（TBD-B06）。

### 非目标

- B 端不展示、不下载、不预览用户文件正文。
- 本次不做登录鉴权、权限分级、操作审计，以上如需立项另行评审。

## 4. 交互规则

### IR-B01 Logo 跳转

- 用户操作：点击顶部圆形 Logo。
- 页面变化：跳转主页。
- 成功判断：可返回主页，无报错。

### IR-B02 头像设置

- 用户操作：点击右上角头像区进入设置。
- 页面变化：上传或更换头像并回显。
- 成功判断：更换后顶部与相关位置一致；失败有提示。

### IR-B03 用户管理查询

- 用户操作：在查询栏输入并触发查询。
- 页面变化：右侧列表刷新为匹配结果，分页重置到第 1 页。
- 成功判断：结果与查询条件一致；空结果有明确空态。

### IR-B04 文件管理约束

- 用户操作：进入文件管理页查看文件。
- 页面变化：仅展示元数据列表，不提供正文预览入口。
- 成功判断：任何情况下均无法在 B 端打开用户文件正文。

## 6. 后端接口现状（可直接复用）

| 接口 | 方法与路径 | 用途 |
|---|---|---|
| 用户详情 | `GET /api/users/{id}` | 用户栏/个人信息/头像展示 |
| 用户分页 | `GET /api/users` | B 端用户管理列表 + 查询 |
| 文件详情 | `GET /api/files/{id}` | 注意 B 端仅允许元数据展示，不可展示正文字段 |
| 公开文件分页 | `GET /api/files` | B 端文件管理列表 |
| 当前用户文件列表 | `GET /api/files/list` | C 端/当前登录用户使用，不适合 B 端按用户筛选 |

约束：B 端调用文件详情时前端必须只取元数据字段，不得渲染 `md_url` 对应的正文内容。
