## 1. 背景与目标

MD Reader 从“图书章节阅读器”升级为“本地文件编辑器”：

- 左侧为导入文件后的文件资源管理器（树状）。
- 右侧为 Markdown 三模式编辑阅读区，默认所见即所得。
- 支持文件导入、会话保留、关闭保存提示、后端持久化（接口待协同）。
- 支持用户栏、滑出面板、设置页、个人信息页（用户数据来自后端接口）。
- 支持浅色 / 深色 / 跟随系统 + 自定义上传图片背景（设置页细节待新设计图）。

### 1.1 范围

在内：布局框架、多功能栏文件树、导入确认、会话保留与保存提示、收起展开动画与响应式、三模式编辑阅读、URL 记忆模式、网络错误提示、用户栏与滑出面板、背景三预设与图片上传最小可用范围。

不在内（本次不做）：登录注册流程、文档新建删除重命名搜索收藏分享、实时协作版本历史导出 PDF、国际化、快捷键体系（后续再考虑）、轮询防丢机制（后续再做）、设置页详细设计（待新设计图）。

### 1.2 术语

- 多功能栏：左侧竖条容器，内容为文件资源管理器 + 底部用户栏。
- 左上角入口：顶部绝对左上角的三条线按钮，展开态收起态均可见。
- 三模式：所见即所得（默认、可编辑）、源码（可编辑、可复制可保存）、预览（只读）。
- 滑出面板：用户栏省略号按钮触发的面板。

## 2. 总体布局

```text
浏览器窗口
└── 页面容器
    ├── 顶部绝对左上角入口（Logo预留 + 三条线按钮）
    ├── 多功能栏（左侧）
    │   ├── 文件资源管理器（树状 + 左下方小+号按钮）
    │   └── 用户栏（底部 + 省略号按钮 + 滑出面板）
    └── Markdown阅读主区（右侧）
        ├── 模式切换（所见即所得 / 源码 / 预览）
        └── 内容区（TinyMCE编辑 / 源码编辑 / 只读预览）
```

布局规则：

- 桌面端多功能栏默认展开，移动端默认收起。
- 收起后多功能栏隐藏，主区横向扩展，左上角入口保持可见。
- 收起展开为平滑滑动过渡。
- 多功能栏为空时直接空白，不展示占位。

## 3. 多功能栏与文件资源管理器

### 3.1 数据结构

树状结构 `FileNode[]`，节点至少含 `id / path / name / type（file|folder）`。是否含大小、更新时间由前端定义并在实现中说明。

### 3.2 导入规则

| 场景 | 操作 | 系统行为 |
|---|---|---|
| 点击导入 | 点击左下方小 `+` 号按钮 | 打开系统文件选择框，选择后导入文件树 |
| 文件拖入编辑框 | 将文件拖入右侧编辑框 | 弹窗询问是否导入，确认导入、取消不导入 |
| 文件夹拖入资源管理器 | 将文件夹拖入左侧多功能栏 | 弹窗询问是否导入，确认导入、取消不导入 |
| 空态 | 未导入任何文件 | 直接空白，不展示占位 |
| 导入失败 | 读取或解析失败 | 提示失败，不写入文件树 |

待后端协同：允许扩展名、大小上限、重名覆盖策略、失败错误码（TBD-01c）。

### 3.3 保留与保存规则

- 刷新页面：保留之前已打开的文件（会话级保留）。
- 关闭页面：不保留；若存在未保存更改，必须提示是否保存该文件。
- 选择保存：与后端协同定义接口，传输文件到数据库持久化保存（接口契约 TBD-14b）。

### 3.4 收起展开

- 桌面端默认展开（`collapsed=false`），移动端默认收起（`collapsed=true`）。
- 左上角三条线按钮在两种状态下均可见，点击切换。
- 动画为平滑滑动过渡（位移类过渡，时长与缓动曲线由前端按常规取值并说明）。
- 快捷键本次不做。
- 移动端断点阈值由前端按常规取值并说明。

### 3.5 左上角入口

- 位置：顶部绝对左上角。
- Logo：默认空白，仅预留形状与按钮位置，等待用户提供图片。
- 图标：三条线（汉堡菜单）。
- 无障碍：需 `aria-expanded / aria-controls`，`aria-label` 建议“展开/收起多功能栏”，最终文案待图片与视觉稿确认。

## 4. 用户栏与滑出面板

- 用户栏位于多功能栏底部，含省略号按钮。
- 用户数据来自后端接口，字段待协同，前端先按 `nickname/username/avatar` 兼容展示。
- 点击省略号打开滑出面板，含“用户设置”“个人信息”两个入口。
- 外点击直接关闭，按 `Esc` 直接关闭。
- 焦点管理暂不做。
- 选择任一入口为路由跳转（非弹窗），跳转后面板关闭。路径待后续设置页设计图确认。

### 5.1 设置页

## 6. Markdown 三模式

### 6.1 模式定义

| 模式 | 默认 | 读写 | 编辑器 | 说明 |
|---|---|---|---|---|
| 所见即所得 | 是 | 可编辑 | TinyMCE | 默认进入 |
| 源码 | 否 | 可编辑，支持复制和编辑保存 | TinyMCE 或代码编辑器（前端决定并说明） | 展示 Markdown 原文 |
| 预览 | 否 | 只读 | 复用现有 `MarkdownRenderer`（`allow-html + sanitize + GFM + Shiki`） | 与现有渲染一致 |

三者互斥，一次只显示一个。

### 6.2 工具栏

必须含三类：

1. 字体加粗 / 加细（“加细”按常规理解落为斜体，前端需在实现中明确标注）。
2. 导入导图。
3. 导入代码块。

导图数据格式与展示方式、代码块语言与插入位置待前端落案说明。

### 6.3 URL 与状态

- `mode` 默认值 `'wysiwyg'`。
- URL 必须记忆模式（参数命名与解析规则 TBD-12b）。
- 刷新后按 URL 恢复同一模式。
- 所见即所得与源码的未保存状态为会话级保留，关闭前必须提示保存。
- 模式切换滚动保留、未保存切换提示待确认。

### 6.4 网络与保存失败

- 网络断开或服务器崩溃直接提示网络错误。
- 轮询防丢机制后续再做，本次仅提示。

## 7. 状态管理建议

基于现有技术栈（Vue 3.5 + vue-router，无 Pinia），不引入新状态库：

| 状态 | 存放 | 持久化 |
|---|---|---|
| `multifunctionCollapsed` | 页面级 `ref` 或 composable | 否（移动端默认 true，桌面端默认 false） |
| `fileTree` | 页面级 `ref` 或 `useFileExplorer` | 会话级保留 |
| `pendingImport` | 导入确认弹窗本地状态 | 否 |
| `userMenuOpen` | 本地 `ref` | 否 |
| `backgroundConfig` | 设置页本地状态 | 待后续设计图 |
| `currentUser` | 后端接口 | 否 |
| `markdownMode` | `MarkdownReader` 内 `ref`，默认 `'wysiwyg'` | 是（同步 URL） |
| `markdownDraft/dirty` | `MarkdownReader` 内 | 会话级保留 |
| `networkError` | 页面级提示 | 否 |

### TC-09 源码

源码与预览内容一致；复制可用；保存提示符合规则。

### TC-11 网络错误

断网保存直接提示网络错误。
