# 项目就绪度评估（2026-11-01）

> 评估对象：`frontend/` + `backend/`
> 评估目标：判断当前项目是否已经是“可行、可使用、可上线、可交付”的 MVP 阅读器
> 评估方式：阅读当前路由、页面、鉴权、公开接口、构建配置与文档；执行前端 typecheck/build、后端 package；尝试执行后端集成测试。

## 1. 结论

| 维度 | 结论 | 说明 |
|---|---|---|
| 可行 | **是** | 公开文章列表、独立阅读页、目录、搜索、分类、阅读设置、进度、登录工作台、管理后台均已成形。 |
| 可使用 | **是（小范围内测/演示）** | 单机部署、少量用户、人工运维的前提下可用；阅读和发布主链路完整。 |
| 可上线 | **有条件，暂不建议直接公网生产** | 主要缺部署/CI/健康检查/备份监控，测试未在当前环境跑通，保存冲突和图片上传仍待补。 |
| 可交付 | **是（课程/简历/内部交付）** | 功能、文档、后端测试代码、构建产物已具备；交付时需说明测试环境与已知限制。 |

一句话：**它已经从“Markdown 工作台”成长为可用的 MVP 阅读器，但还不是“生产就绪”的阅读产品。**

## 2. 已具备的能力

### 2.1 阅读器主链路

- `/` 公开文章列表：搜索、分类筛选、分页、封面、摘要、作者、更新时间、空态/错误重试。
- `/read/:id` 独立阅读页：标题、元信息、正文、目录、阅读进度、复制链接、移动端适配。
- 公开接口匿名可读：`GET /api/files`、`/api/files/{id}`、`/api/files/{id}/content`、`/api/files/categories`。
- 阅读设置：字号、行高、内容宽度、代码字号，localStorage 持久化。
- 阅读增强：代码块复制、图片懒加载、外链新窗口与安全 `rel`、标题锚点。
- 阅读进度：滚动进度条 + 上次阅读位置。

### 2.2 工作台与发布

- 登录、注册、强制首次改密、自助改密。
- 文件树、新建文件/文件夹、导入、导出、云端保存、本地暂存。
- 文件重命名、移动、删除 UI 已接入。
- 工作区文件名搜索。
- 阅读排版设置与公开列表共用真实后端数据。

### 2.3 安全与权限

- JWT 每次请求回查数据库，校验用户状态、角色和 `token_version`。
- 禁用、降权、改密后旧 Token 失效。
- 管理员接口改用 `@RequireAdmin` 注解，不再依赖原始 URI 字符串。
- 管理端只返回元数据，不读取用户正文。
- 登录失败限流（IP + 用户名，5 次/15 分钟）。
- 公开文件匿名读取，私有/草稿仅所有者可读。
- Markdown 预览开启 `sanitize`，没有发现裸 `v-html`。

### 2.4 文档与测试基础

- 后端已有 25 个集成测试，覆盖鉴权、管理端权限、公开/私有文件、文件重名、错误状态码、公开文章元数据。
- `docs/` 已整理出 API、设计、后端审查、前端差距、部署说明和公开页面接口清单。
- 前端 typecheck/build 通过；后端 package 通过。

## 3. 本次实际验证结果

### 3.1 前端

```text
npm run typecheck  -> 通过
npm run build      -> 通过
```

构建输出有两个提示：

- `:deep` 伪类告警：来自 `x-markdown-vue` 样式，当前不影响构建。
- 部分 chunk 超过 500 kB：Shiki 语言包和主入口较大，属于性能优化项，不是阻塞项。

### 3.2 后端

```text
mvn -DskipTests package -> BUILD SUCCESS
mvn test                -> 25 个测试全部报错
```

测试失败原因不是断言失败，而是 **本机 MySQL 未启动**：

```text
Communications link failure
Connection refused: getsockopt
```

当前测试配置要求 `localhost:3306/mdreader_test`、`root/1234`。本机 MySQL 服务处于停止状态且无权限启动，因此本次无法完成测试验证。

**结论：测试代码存在，但当前环境没有跑通；上线前必须在 CI 或可用的测试数据库中跑通。**

### 3.3 部署与工程化

- 有生产 Nginx 示例：`docs/frontend/reader-deploy-2026-10-31.md`。
- 没有 Dockerfile、docker-compose、CI 配置、Actuator 健康检查、备份/监控脚本。
- 没有根目录 README，后端目录也没有独立 README/`.gitignore`。
- 前端没有 `vitest`、Playwright、ESLint；后端测试依赖真实 MySQL，不是容器化/临时数据库。

## 4. 距离“可上线”还差什么

### P0：上线前建议补齐

1. **测试必须在 CI 中跑通**
   - 当前 `mvn test` 依赖本机 MySQL，环境不可用时全红。
   - 建议使用 Testcontainers MySQL 或 CI service，保证 `mvn test` 可重复执行。
   - 前端至少补关键路径 E2E：公开列表 → 阅读页 → 登录 → 工作台保存。

2. **部署与运维基线**
   - 增加 Dockerfile、docker-compose、CI、健康检查、日志/错误监控、数据库备份说明。
   - 明确生产环境变量：`SPRING_PROFILES_ACTIVE=prod`、`JWT_SECRET`、`DB_*`、`CORS_ALLOWED_ORIGINS`。
   - 上传目录需持久化，不能放在容器临时层。

3. **保存冲突检测**
   - 当前保存是整篇覆盖，没有版本号/`updatedAt` 条件更新；多标签页或多设备会最后写入者覆盖。
   - 建议后端 `PUT /api/files/{id}` 增加版本号或 `updatedAt`，冲突返回 409；前端提示重新加载。

4. **正文图片上传**
   - 目前图片以 data URL 写入 Markdown，多图容易超过 10 MB。
   - 建议增加通用图片上传接口，正文只存 URL；并给出超限提示。

### P1：影响生产质量

5. **生产会话策略**
   - 生产 Token 默认仍为 7 天；建议缩短 Access Token 有效期，补刷新/撤销策略。
   - Token 仍存 localStorage；若安全要求高，考虑 httpOnly Cookie。

6. **单机内存状态**
   - 验证码、登录失败计数都在单机内存；多实例部署会不一致。
   - 单实例上线可以接受，扩容前需迁移到 Redis 或共享存储。

7. **SEO 与分享**
   - 仅有 `document.title`，没有 description/Open Graph/canonical/sitemap。
   - 若公开文章要被搜索引擎收录，需要预渲染或 SSR。

8. **阅读增强**
   - 图片灯箱、上下篇/相关推荐、收藏/书签、阅读历史尚未实现；这些不等于 MVP 阻塞，但影响“阅读产品”的完成度。

9. **前端工程质量**
   - 无前端测试、无 lint；建议至少补 Markdown 清洗、存储、路由状态、阅读页 E2E。
   - `WorkspaceView` 仍同步引入 TinyMCE/Shiki，首屏体积偏大。

### P2：体验与边界

10. **分类深链初载**
    - 带 `?kind=分类名` 首次进入列表页时，分类尚未加载，首次请求可能不带分类参数；建议分类加载完成后再决定是否重载。
11. **图片灯箱、脚注/数学/图表、打印/PDF**
    - 属于增强功能，可按产品优先级排期。

## 5. 交付建议

### 作为课程/简历/内部演示项目

**可以交付。** 建议交付时说明：

- 阅读器主链路已完成；
- 后端测试存在但需要 MySQL 测试库；
- 生产部署需要按 `docs/frontend/reader-deploy-2026-10-31.md` 配置 Nginx；
- 已知限制：保存冲突、图片 data URL、收藏/历史、SEO。

### 作为公网生产服务

**建议先完成 P0 四项再上线：**

1. CI 中跑通后端测试 + 前端关键 E2E；
2. Docker/CI/健康检查/备份监控；
3. 保存冲突检测；
4. 正文图片上传。

完成后再评估：缩短 Token 有效期、共享验证码/限流、SEO/预渲染。

## 6. 最终判定

- **可行：通过。**
- **可使用：通过（小范围、单实例、人工运维）。**
- **可上线：有条件通过，不建议直接面向公网生产。**
- **可交付：通过（课程/简历/内部交付），需附带已知限制和测试环境说明。**
